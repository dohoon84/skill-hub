## 공휴일 조회 도구

Nager.Date 공개 API를 사용하여 전 세계 90개국의 공휴일 정보를 조회합니다. API 키 없이 사용할 수 있습니다.

### 사용 가능한 도구

- **get_public_holidays**: 특정 국가의 연도별 공휴일 목록 조회

### 파라미터

- `country_code`: ISO 3166-1 alpha-2 국가코드 (예: KR, US, JP, DE, GB)
- `year`: 조회할 연도 (예: 2024, 2025)

### 사용법

- 여행 전 목적지 현지 공휴일 확인
- 비즈니스 일정 수립 시 해외 휴일 파악
- 특정 날짜가 현지 공휴일인지 확인

### 지원 국가 (주요)

KR(한국), US(미국), JP(일본), CN(중국), DE(독일), GB(영국), FR(프랑스), SG(싱가포르), AU(호주) 외 다수
