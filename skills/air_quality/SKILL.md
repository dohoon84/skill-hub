## 대기질 조회 도구

OpenAQ 공개 API를 통해 전 세계 주요 도시의 실시간 대기질 데이터를 조회합니다. API 키 없이 사용할 수 있습니다.

### 사용 가능한 도구

- **get_air_quality**: 특정 도시의 현재 대기질 지표 조회

### 파라미터

- `city`: 조회할 도시명 (영문, 예: Seoul, Beijing, Delhi, Tokyo)

### 반환 데이터

- **PM2.5**: 초미세먼지 농도 (μg/m³)
- **PM10**: 미세먼지 농도 (μg/m³)
- **AQI**: 대기질 지수 (Air Quality Index)
- **NO2, O3, CO**: 이산화질소, 오존, 일산화탄소 농도

### AQI 기준

| 범위 | 등급 | 설명 |
|------|------|------|
| 0~50 | 좋음 | 대기 오염 위험 없음 |
| 51~100 | 보통 | 일반인 영향 없음 |
| 101~150 | 민감군 주의 | 민감한 사람 주의 |
| 151~200 | 나쁨 | 모든 사람 영향 |
| 200+ | 매우 나쁨 | 야외 활동 자제 |

### 사용법

- 야외 활동 계획 전 대기질 확인
- 도시별 환경 비교 분석
- 건강 관련 의사결정 지원
