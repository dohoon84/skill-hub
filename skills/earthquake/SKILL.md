## 지진 데이터 조회 도구

미국 지질조사국(USGS)의 공개 API를 사용하여 전 세계 실시간 지진 정보를 조회합니다. API 키 없이 사용할 수 있습니다.

### 사용 가능한 도구

- **get_earthquakes**: 최근 지진 목록 조회

### 파라미터

- `min_magnitude`: 최소 규모 필터 (기본값: 4.5, 권장 범위: 2.5~9.0)
- `hours`: 최근 몇 시간 이내 데이터 (기본값: 24)
- `limit`: 최대 반환 건수 (기본값: 10)

### 반환 데이터

- **규모(Magnitude)**: 리히터 규모
- **발생 시간**: UTC 기준
- **위치**: 도시명 및 위/경도
- **진원 깊이(Depth)**: km 단위
- **쓰나미 가능성 여부**

### 규모별 기준

| 규모 | 분류 | 특징 |
|------|------|------|
| 2.5~4.4 | 경미 | 일부 지역 진동 느낌 |
| 4.5~5.9 | 중간 | 피해 가능성 낮음 |
| 6.0~6.9 | 강한 | 인근 지역 피해 가능 |
| 7.0~7.9 | 대규모 | 광역 피해, 쓰나미 가능 |
| 8.0+ | 초대형 | 대규모 재해 |

### 사용법

- 글로벌 지진 활동 모니터링
- 특정 지역 여행 전 지진 리스크 확인
- 재난 리스크 분석에 활용
